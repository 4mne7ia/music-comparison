
Music Comparison

Опис проєкту

Навчальний вебпроєкт для порівняння популярних музичних платформ: Spotify, Apple Music та YouTube Music.

Мета проєкту — створити просту та зручну таблицю порівняння музичних сервісів із використанням HTML та CSS.

Використані технології

- HTML5
- CSS
- Локальний шрифт Oswald (WOFF2)
- GitHub Pages

Перевірка

Сторінку фактично перевірено у Google Chrome.

Друге середовище для порівняння недоступне.

Локальний шрифт завантажується коректно, таблиця та контентний контейнер відображаються стабільно.
